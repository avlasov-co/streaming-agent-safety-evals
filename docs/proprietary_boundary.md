# Proprietary Boundary

This repository is a public research artifact inspired by general problems encountered in real-time ML systems.

It does not contain:

- proprietary Polinash code
- private model weights
- production feature engineering
- private datasets
- exchange API integrations
- trading logic
- infrastructure configuration
- secrets or credentials

The benchmark is synthetic and focuses only on general safety evaluation questions: distribution shift, overconfident errors, abstention, constraint violations, and unsafe behavior in sequential decision systems.
